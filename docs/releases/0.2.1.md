# RustChrome 0.2.1

Pre-release. Beta software, not a stable browser.

A patch release on top of the 0.2.0 beta. No new features: one data-loss bug fixed,
three failure modes made visible, and the documentation rewritten to say what the
code actually does.

## Fixed

**Your settings no longer get erased.** Toggling the theme rewrote `prefs.json` with
only two keys, silently destroying the zoom level, the anti-fingerprinting setting,
the cleanup preference, the session mode and any custom search engines. The file now
has exactly one typed writer, and a change to one setting provably leaves the others
alone (three new tests).

**Dropped UI callbacks are counted.** If a click arrived while the browser was busy
inside another callback, it used to be discarded without a trace. It is now counted
and reported in the smoke trace.

**Failed layout calls are counted.** A failed `SetBounds` looked exactly like a
successful one — which is how 0.2.0 could build a window with no toolbar while every
WebView2 call reported success. Failures are now visible in the trace.

**Unsafe code has a stated contract.** The three COM-heavy modules document their
threading assumptions instead of leaving 53 `unsafe` blocks unexplained.

## New documentation

* `docs/ARCHITECTURE.md` — how the two shells and the shared core fit together.
* `docs/SECURITY-REVIEW.md` — threat model, what the browser controls, what is still
  weak.
* `docs/PERFORMANCE.md` — the measured numbers and why they should be read
  sceptically.
* `docs/RELEASE.md` — how a release is built, verified and published.
* `docs/PRIVACY.md` — a claim-by-claim table separating **verified**, **partial** and
  **not implemented**.
* The wiki gained Architecture and Performance pages.

## Unchanged, still true

Known bugs are listed in `docs/QA.md`: Linux ignores per-site permission rules and
has no download manager or settings surface; recently-closed depth differs between
platforms; the Windows title refreshes only on load; bookmarks are flat; crash
recovery does not ask. No ad blocker, no password manager, no extensions beyond
userscripts, no macOS or Android.

Nothing here is marked stable anywhere. It is a beta with holes, and its own
documentation says so.
